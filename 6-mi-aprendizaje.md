# COMPLETAR  
Comparando sus conocimientos antes de hacer la práctica con sus conocimientos después de hacer la tarea, explicar los principales aprendizajes logrados para beneficio de su formación profesional.  
Si solucionó un problema presentado o utilizó otros comandos que no se mencionan al realizar la práctica también se debe documentar.

Después de hacer la práctica aprendí y entendí mejor lo que es la creación y conección de contenedores dentro de una misma red de Docker y la configuración de las variables de entorno para servicios como PostgreSQL y Drupal. También entendí mejor cómo funcionan los puertos publicados y cómo un cliente, como en este caso pgAdmin, puede conectarse a un servidor de base de datos dentro de la red solo usando el nombre del contenedor.

Aprendí igualmente el uso y la importancia de los volúmenes nombrados, los cuales permiten mantener los datos almacenados de forma persistente, incluso si el contenedor se detiene o elimina. Esto me ayudó a entender cómo Docker separa la información de la aplicación del ciclo de vida del contenedor, garantizando la integridad de la base de datos y los archivos del sitio.
